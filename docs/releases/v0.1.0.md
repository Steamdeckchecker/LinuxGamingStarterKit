## Linux Handheld Starter Kit — v0.1.0

**Erste öffentliche Testversion / First public test release**

[Webseite / Website](https://linux-handheld-starter-kit.cocoabloom514.chatgpt.site/) · [Deutsch](https://github.com/Steamdeckchecker/LinuxGamingStarterKit#readme) · [English](https://github.com/Steamdeckchecker/LinuxGamingStarterKit/blob/main/README.en.md) · [Steam Deck Checker auf YouTube](https://www.youtube.com/@SteamDeckChecker/)

### Deutsch

Ein geführter Installer für Linux-Handhelds mit SteamOS, CachyOS oder Bazzite.
Zur Auswahl stehen Deutsch, Englisch, Spanisch, Französisch, Russisch,
vereinfachtes Chinesisch und Japanisch.

Tests wurden auf SteamOS, CachyOS und Bazzite durchgeführt.

- Geräteprofile: Steam Deck LCD/OLED, Steam Machine, MSI Claw, Legion Go und anderer Handheld.
- Passende Startvideos, Decky Loader, 23 eingebettete Plugin-Empfehlungen und eine freie Plugin-Auswahl.
- 16 optionale Flatpak-Apps sowie RetroDECK oder EmuDeck.
- Steam-Verknüpfungen für Apps und Emulationslösungen; Steam-Neustart nach drei Sekunden Wartezeit.
- Decky-sudo-Korrektur, synchrone Installationen, sichtbarer Terminalfortschritt, Diagnose und Probelauf.

**Start:** Im Desktop-Modus nur `Linux-Handheld-Starter-Kit.desktop` aus den
Assets herunterladen, bei Bedarf als ausführbar/vertrauenswürdig freigeben und
doppelklicken. Alternativ nur `install.sh` herunterladen und mit
`bash install.sh` als normaler Benutzer starten.

Startvideos anschließend in Steam unter **Einstellungen → Anpassungen →
Startvideo** aktivieren. `bash install.sh --check` prüft Voraussetzungen;
`bash install.sh --dry-run` bietet einen Probelauf.

### English

A guided Linux handheld installer targeting SteamOS, CachyOS and Bazzite,
with German, English, Spanish, French, Russian, Simplified Chinese and Japanese UI.

- Six device profiles, matching startup movies, Decky Loader and 23 embedded plugin recommendations.
- Searchable plugin catalogue, 16 optional Flatpak apps, RetroDECK or EmuDeck.
- Optional Steam shortcuts and automatic Steam restart after a three-second pause.
- Fixed sudo authorization for Decky, sequential installations, visible progress and dry-run mode.

**Start:** In Desktop Mode download only `Linux-Handheld-Starter-Kit.desktop`
from Assets, allow execution/trust if prompted and double-click it.
Alternatively download only `install.sh` and run `bash install.sh` as your normal
user. No additional Python packages are needed.

Enable installed movies in Steam's **Settings → Customization → Startup Movie**.
Use `bash install.sh --check` for diagnostics and `--dry-run` to simulate setup.

Python 3.9+, Bash, an x86_64 Linux desktop and Zenity or KDialog are required.
Tests have been carried out on SteamOS, CachyOS and Bazzite.
Third-party apps/plugins have their own compatibility requirements.
See the README for prerequisites and the complete workflow.
