# v0.3.1 — Backlog 1.0.4-DE1

- Das Starterkit installiert jetzt die deutsche Backlog-Version 1.0.4-DE1 (bisher 1.0.2-DE1).
- Verbessertes Zusammenführen von Erfolgsdaten aus Steams Übersicht und dem Cache des jeweiligen Spiels.
- In Steam versteckte Spiele samt Screenshots werden standardmäßig ausgelassen und bereits synchronisierte Daten beim nächsten Abgleich bereinigt. Optional in der installierten config.js unter library die Option showHidden: true setzen.
- Szenenauswahl, Shuffle, Dauer und Uhrformat einer vorhandenen config.js bleiben erhalten; auch ältere Konfigurationen funktionieren weiter.
- Downloads, Prüfsummen, eigenständige Starter, Dokumentation und sieben Sprachversionen der Webseite aktualisiert.
- Das aktuelle Komplettpaket enthält nur die neue Runtime. Die alte Runtime bleibt im Repository verfügbar, damit ältere einzelne Starter weiter funktionieren.

Die Runtime-Dateien, Schriften, Lizenzen, Anleitungen und neun Regressionstests entsprechen dem veröffentlichten Paket: https://github.com/Steamdeckchecker/backlog-german/releases/tag/v1.0.4-DE1 . Nur die großen Vorschaubilder sind nicht enthalten. Ein Test der Starterkit-Integration im Steam-Spielmodus auf echter Hardware steht noch aus.

## English

Updates the bundled German Backlog screensaver to 1.0.4-DE1, including per-game achievement caches and hidden-game/screenshot filtering. Existing configuration is preserved. Includes refreshed launchers, checksums, documentation and website, plus the nine Backlog regression tests. Legacy installers retain access to their original runtime in the repository.
