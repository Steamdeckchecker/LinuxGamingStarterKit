# v0.2.0 — LiveWallpaper, 28 Plugins & Desktop-Links

## Deutsch

- Die Empfehlungen enthalten jetzt genau die 28 gewünschten GitHub-Repositories.
- Neuer optionaler Schritt **vor EmuDeck/RetroDECK**: LiveWallpaper 0.3.1 per **Ja/Nein** installieren.
- Bei Ja wird **Neon-Emblem** mit dem mitgelieferten Steam-Deck-Checker-Logo aktiviert: 24 FPS, 60 % Renderauflösung und Vollbild-Pause.
- Desktop-Verknüpfungen zu **Linux Starterkit** und **Steam Deck Checker** werden ohne Rückfrage mit den Original-Projektlogos angelegt.
- Shell-Installer, Doppelklick-Starter, Dokumentation und Webseite wurden aktualisiert.

**Starten:** Im Desktop-Modus `Linux-Handheld-Starter-Kit.desktop` herunterladen
und öffnen. Alternativ:

```bash
curl -fL --retry 3 -o install.sh "https://github.com/Steamdeckchecker/LinuxGamingStarterKit/releases/download/v0.2.0/install.sh" && bash install.sh
```

Das Wallpaper benötigt **KDE Plasma 6**, **QtWebEngine**, `kpackagetool6` und
`qdbus6` beziehungsweise `qdbus`. Fehlende Voraussetzungen werden gemeldet;
der Installer verändert dafür keine Systempakete. Nach dem Aktualisieren eines
bereits laufenden Wallpaper-Moduls einmal ab- und wieder anmelden.

**Prüfung:** 85 automatisierte Installer-Tests, inklusive Erstinstallation und
Update des beigefügten Wallpaper-Installers mit isolierten KDE-Werkzeugen.
Ein vollständiger Test der neuen Integration auf einem Plasma-6-Desktop steht aus.

## English

- Recommendations now contain exactly the requested 28 GitHub repositories.
- New optional **Yes/No** step **before EmuDeck/RetroDECK**: install LiveWallpaper 0.3.1.
- Yes activates **Neon Emblem** with the included Steam Deck Checker logo:
  24 FPS, 60% rendering resolution and fullscreen pause.
- **Linux Starterkit** and **Steam Deck Checker** desktop links are added
  automatically with the original project logos, without another prompt.
- Both standalone launchers, documentation and all seven website languages are updated.

Download and open `Linux-Handheld-Starter-Kit.desktop` in Desktop Mode, or use
the terminal command above as your normal user.

The wallpaper requires **KDE Plasma 6**, **QtWebEngine**, `kpackagetool6` and
`qdbus6` or `qdbus`. Missing prerequisites are reported without changing system
packages. Log out and back in after upgrading an already running wallpaper.

**Validation:** 85 automated installer tests, including fresh installation and
upgrades of the supplied wallpaper installer against isolated KDE tools.
The new integration still requires a full Plasma 6 desktop test.

Downloads include the self-contained desktop launcher, the alternative shell
installer, the source ZIP with the original wallpaper archive, and SHA-256 checksums.
