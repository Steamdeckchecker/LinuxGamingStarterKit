# v0.3.0 — Backlog-Bildschirmschoner

- Optionaler Backlog-Schritt nach LiveWallpaper und vor EmuDeck/RetroDECK.
- Mitgelieferte deutsche Version 1.0.2-DE1 von Backlog (Original: Glidian, MIT). Datum, Spielstunden, letzte Spielzeit und Erfolge auf Deutsch.
- Neue Installationen: Mosaik, Drift, Flip und Wellen im Shuffle, je 5 Minuten, 24-Stunden-Uhr. Vorhandene config.js bleibt erhalten.
- Automatische Aktualisierung der lokalen Steam-Bibliothek per Benutzertimer alle 15 Minuten.
- Aktivierung in Steam: Einstellungen → Anpassung → Bildschirmschoner → backlog.
- Geprüfter Download für eigenständige Starter; Runtime-Paket mit allen Laufzeitdateien, Schriften, Lizenzen und Anleitungen. Nur die großen Vorschau-Bilder aus docs/ sind weggelassen.
- Webseite und Anleitungen in sieben Sprachen aktualisiert; die Bildschirmschoner-Ausgabe bleibt ausdrücklich Deutsch.

## English

Adds the optional German Backlog 1.0.2-DE1 screensaver after LiveWallpaper and before emulation. New installs shuffle all four scenes every five minutes; existing configuration is preserved. Includes local library refresh, the original licenses, a checksum-pinned runtime package and updated website/downloads. A real Steam Game Mode hardware test of this integration is still pending.
